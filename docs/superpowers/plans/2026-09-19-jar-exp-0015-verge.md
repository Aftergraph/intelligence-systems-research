# VERGE Evolutionary Controller Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement an offline, deterministic, reproducible research harness for JAR-EXP-0015 VERGE that can compare constrained multi-objective/QD evolutionary policy search against preregistered baselines without production side effects.

**Architecture:** Build a small Python package under `experiments/verge/` with immutable genome/receipt models, hard feasibility gating, Pareto selection, a MAP-Elites-style archive, adaptive operator credit, deterministic benchmark adapters, and frozen analysis outputs. Production integrations are explicitly out of scope for the first slice.

**Tech Stack:** Python stdlib + repository's existing test environment; no network requirement for S1/S2 deterministic phases.

**Spec:** `docs/superpowers/specs/2026-09-19-jar-exp-0015-verge-design.md`

## Global Constraints

- Research-only: no production mutations.
- Authority is external to the genome and cannot be widened by variation.
- UAR/evidence-integrity violations are hard feasibility failures.
- Self-reported completion cannot count as verified success.
- Every candidate and evaluation must be reconstructable from hashes + seed + operator receipt.
- Baselines must receive matched evaluation budgets where representations permit.
- No confirmatory execution before analysis manifest and benchmark hashes are frozen.

## Review Focus

- Mutation must never alter frozen benchmark/verifier semantics.
- Candidate hashes must be stable under deterministic serialization.
- Invalid candidates must remain recorded rather than silently dropped.
- Archive replacement must preserve descriptor-cell correctness and exact lineage.
- Adaptive operator credit must not use self-reported success fields.
