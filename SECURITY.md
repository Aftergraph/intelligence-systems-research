# Security Policy

This is a research/model repository. Claims, artifacts, and datasets may be reproducibility-sensitive but are not a production trust surface.

## Reporting

Do not publish suspected credential exposure or exploitable behavior publicly. Report privately to the maintainer (@JonasAbde) with a minimal reproduction and affected commit.

## Secrets

No credentials, API tokens, or signing keys belong in this repository, including in fixtures, notebooks, or model artifacts.

## Supported versions

Only the current `main` branch is maintained.
