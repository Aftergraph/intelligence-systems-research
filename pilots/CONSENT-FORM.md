## 1. Study Purpose

You are invited to participate in a research study investigating how humans interact with AI assistant tools in enterprise workflows. We are testing four interface designs:
1. **Chat-Only** (natural language conversation)
2. **Traditional GUI** (forms and buttons)
3. **Hybrid Agent UI** (chat with embedded widgets)
4. **Mission-Centric UX** (declarative contracts, exception-first alerts, progressive disclosure)

You will be randomly assigned to one of these four interfaces. During the session, you will complete four realistic work tasks while using the assigned interface.

---

## 2. What You Will Do

- **Duration**: 60–90 minutes
- **Tasks**: Four multi-step workflows (deployment, database migration, adversarial security test, budget recovery)
- **Measures**: 
  - Number of interventions/actions per task
  - NASA-TLX cognitive workload questionnaire (after each task)
  - System Usability Scale (end of session)
- **Data Collected**:
  - Session audio/video recording (optional, see §3)
  - Telemetry: timestamps, keystroke counts, approval decisions
  - Survey responses (demographics, workload ratings)
